# Changelog

**Not a release log.** The releases are the signed `v*` tags and their GitHub
releases (README, *Versions and releases*). This file holds what this
repository's documents used to say. When a sentence in a tracked document is
found dead, the change that finds it rewrites the sentence to what is true at
`main`, and moves the dead text here in the same commit, dated, with what it
was read against. A reader carrying an old claim then finds it here, labelled
dead, rather than finding nothing.

**FROZEN, entry by entry: read every date below as "true when written".**
Nothing in this file is current. Each entry quotes the dead text, says when it
was read dead and against what, and names the commit its wording entered with,
from `git log --reverse -S"<phrase>" -- <file>`.
